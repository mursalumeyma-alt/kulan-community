# Kulan

Kulan is a community events website inspired by Meetup. It helps people discover local events, connect with communities, and join activities across Minnesota.

## Features

- 🏠 Responsive homepage
- 🔍 Event search bar
- 📅 Featured events
- 🎯 Join Event buttons
- 👥 Community groups
- ℹ️ About page
- 📞 Contact page
- 📱 Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
